# ClipForge

Автоматический инструмент для создания вирусных клипов с АП-обходом.

## Возможности

- 📤 Загрузка видео через drag & drop или URL
- 🔍 Автоматический анализ вирусных моментов
- ✂️ Создание клипов с АП-обходом
- ⚙️ Настройка модификаций видео
- 📊 Дашборд со статистикой
- 📅 Планировщик публикаций
- 👥 Управление несколькими аккаунтами

## Установка

```bash
pip install -r requirements.txt
```

## Требования

- Python 3.8+
- FFmpeg
- yt-dlp

## Запуск

```bash
python app.py
```

## Структура проекта

- `app.py` - основное Flask приложение
- `viral_analyzer.py` - анализ вирусных моментов
- `ap_bypass.py` - обход АП (антиспам)
- `analytics.py` - аналитика и статистика
- `scheduler.py` - планировщик публикаций
- `account_manager.py` - управление аккаунтами
- `playlist_processor.py` - обработка плейлистов
- `title_templates.py` - шаблоны заголовков
